# ComandaUp Impressão

Aplicativo para Windows que imprime os pedidos do **ComandaUp** direto na impressora térmica da cozinha.

## Como instalar

1. **[Baixar o instalador](https://github.com/joaohenryquecunha/comandaup-impressao/releases/latest/download/ComandaUp-Impressao-Setup.exe)** no computador que fica ligado à impressora.
2. Abra o arquivo baixado. Se aparecer "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.
3. No ComandaUp, abra **Gestão → Estação de impressão** e clique em **Conectar este computador**.

O aplicativo encontra a impressora (rede ou USB), imprime um teste e se atualiza sozinho.

Este repositório guarda apenas os instaladores.
